# Lessons

One line per video: what worked, what to stop doing.

| Date | Video | Lesson |
|---|---|---|
| 2026-10-15 | First AI reel (goddess on a lion, Instagram) | 401 views but **0:02 average watch time**, 0 shares/saves/follows. Opened on a slow macro (water drops + part of a paw), grid tile was black (no cover), caption was about me ("My first AI video"), music was a Western dance track. Next: open on the face/hero shot, set a cover, devotional caption + hashtags, fitting audio. |
| 2026-11-05 | Diwali Lakshmi (edit) | Veo adds particles (coins, sparks) that drift across faces when the prompt mentions coins or fireworks near a close-up. For a calm end card, a slow push-in on the clean still (ffmpeg zoompan) beats a Veo clip and costs 0 credits. Check every shot with a 2 fps contact sheet before posting. |
| 2026-11-05 | Diwali Lakshmi (prompts) | A detailed character block + one action per shot + motion-only Flow prompts gave 10/10 usable Veo clips first try (100 credits, 0 re-rolls). |
| 2026-11-05 | Diwali Lakshmi (review) | Veo adds long blinks and keeps actions going (person walks off): check close-ups with labelled 2 fps frame strips and trim to the good window before cutting. |
| 2026-11-05 | Diwali Lakshmi (Telugu text) | Telugu needs libass complex shaping (ASS + `shaping=complex`), letter spacing 0, and a Latin fallback font; `subtitles` and `drawtext` break clusters. |
| 2026-11-05 | Diwali Lakshmi (voice) | Owner's own Telugu voice, split into one file per line, is easy to place on shots and sounds better than AI Telugu voices. |
| 2026-11-05 | Diwali Lakshmi (publishing) | Confirm the exact publish time in chat before the last click; Chrome uploads are limited to 10 MB (two-pass re-encode to fit). |
| 2026-11-08 | Diwali Lakshmi (3-day numbers) | Hero-face opening + devotional caption + Telugu voice: IG average watch 0:02 → 0:04, first share and follow; YouTube Short 0:25 avg (85%) and +4 subs from 256 views. But 75.8% swipe away on YouTube: the very first second still needs motion + the question. |
| 2026-11-08 | Happy Diwali (structure) | Reference-reel structure (fast 1–2 s cuts, adult reaction faces, one spectacle, gold Telugu title card) worked: the YouTube Short averaged **132.7 % viewed** in its first 3½ hours (people rewatched), against 85 % for the Lakshmi Short. Keep this structure for festival greetings. |
| 2026-11-08 | Happy Diwali (stills) | Two hand actions in one prompt ("holds a diya" + "namaste") gave a **three-handed** grandmother; "head on his shoulder" gave a **bent neck**. One hand action per still, ask for upright heads, and count hands and arms on every still before animating. |
| 2026-11-08 | Happy Diwali (stills) | "Anamorphic film still" makes Nano Banana add **black letterbox bars**. Always write "FULL-FRAME 9:16 edge to edge, no black bars". Generating stills inside Flow (Nano Banana, 0 credits) avoids Gemini's stuck full-size downloads. |
| 2026-11-08 | Happy Diwali (credits) | 10 clips ≈ 100 credits; a failed clip ("audio generation" error) is not charged. Approved budget (120) was enough. |
| 2026-11-08 | Happy Diwali (grade) | Do all colour work in **RGB** (`format=gbrp`): a screen-blend glow in YUV turned the whole video **purple**. Always check a graded frame next to the ungraded one before rendering the full video. |
| 2026-11-08 | Happy Diwali (grade) | The owner's "blurry" was my bug: ffmpeg `blend=all_mode=normal` weights the **first** input by the opacity, so a "12 % mist" was 88 % blur. Compare a **100 % face crop** (raw vs graded) after any grade change; output 1080×1920 (lanczos + `cas` sharpen) so platforms compress less. |
| 2026-11-08 | Happy Diwali (grade) | Guessing a grade went wrong twice (too dark and orange). Matching an owner-supplied reference **by numbers** (black level, average brightness, saturation, RGB in shadows/mids/highlights) got close in one pass. Different references want different looks: `film` (matte) and `rose` (deep blacks, rose shadows; now the default). |
| 2026-11-08 | Happy Diwali (look) | Grading can't fix age, wrinkles or plain jewellery: **the still decides the look**. Owner rules from now: young adults only; deities flawless and beautiful/handsome; otherworldly celestial jewellery. Still quality gate in the skill; owner OKs a contact sheet before any credits. |
| 2026-11-08 | Happy Diwali (music) | YouTube Studio on desktop can't add music to a Short: mix a YouTube Audio Library track in with ffmpeg (YouTube Audio Library License = no credit needed). I can't hear audio: send the owner a preview to approve on the phone. |
| 2026-11-08 | Channel setup | Multi-language audio on YouTube needs **Advanced features** (phone verification only unlocks Intermediate). The AI Studio speech playground needs a Gemini API key. Instagram's Meta AI translation dubs Telugu speech, so reels need narration for it to work. Plan: `docs/multilingual-voice-plan.md`. |
| 2026-11-10 | Karthika (clips) | **The prompt words are taken literally.** "The flame grows" → a huge flame over her face; "she looks up" → eyes above the camera. Write the end state you want: "flame stays small, fingertip size", "eyes stop at camera level, never above". |
| 2026-11-10 | Karthika (clips) | **Veo 3.1 Lite can't do object hand-offs** (diya lifted off a plate onto water): 3 tries gave a duplicated diya or a vanishing plate, even with a Nano Banana end frame (first + last frame). Show state changes **with cuts** instead (hold → insert of the floating diya → empty-plate still push-in, 0 credits). Plan this at the shot-list stage, not after 30 credits. |
| 2026-11-10 | Karthika (credits) | Re-rolls cost more than the batch: 50 for 5 clips, then 40 for 4 re-rolls. Read each motion prompt for "grow / look up / release / drop" before approving. The Flow balance showed **no daily +50** (130 → 40, one pool resetting 15 Nov): plan from the shown balance, not the assumed 50/day. |
| 2026-11-10 | Karthika (Flow agent) | With first + last frame attached, Flow's agent proposed **6 videos / 60 credits** for one shot. Always read the count and cost in the confirmation; Reject and re-ask "exactly ONE video, x1, 10 credits". |
| 2026-11-10 | Karthika (review) | The owner caught all three motion errors from the phone; Flow's in-page preview wouldn't play for Claude via Chrome. Download and contact-sheet every clip before calling it OK; don't judge from the first frame. |
| 2026-11-10 | Samudra Manthan (plan) | A 5-min film (~650–850 credits, 2+ weeks before anything posts) is too big for a new channel with 2 s average watch time. Split into 3 × 60–75 s episodes with cliffhangers; make the hero episode first. |
| 2026-11-11 | Karthika (voice) | **A TTS style prefix is read aloud.** `tts.sh` sent "Read this in Telugu… calm and reverent: <text>" and Gemini spoke the English instruction (about 4 s) before the Telugu; I had timed the whole cut to that audio. Default style is now empty. Check every narration before cutting: duration vs word count (~36 words ≈ 18 s, not 28 s), `silencedetect` for the line gaps, and the owner listens before the cut is built. |
| 2026-11-11 | Karthika (shots) | Veo made the couple **sway back and forth** holding the diya plate, the second time a hand-held-object shot failed. Any moment with hands plus an object becomes a 0-credit push-in on a still. Check that at the shot-list stage, not after the clip. |
| 2026-11-11 | Karthika (edit) | Hard cuts at 1.4–2.6 s on the line gaps are cheap on this laptop (cut 50 s; rose grade 1080p ~10 min; 18 s clip). Keep the pipeline as scripts (`cut.sh`, `build_v2.sh`) so a retime is one command; never `pkill -f` a pattern that appears in your own command line (it killed my shell). |
| 2026-11-11 | Delivery | A video sent as a file did not show on the owner's phone. A private Artifact page with the video embedded as a data URI (under 16 MB) plays in the app. Use that for previews. |
| 2026-11-11 | Samudra Manthan (refs) | One prompt that assigns each of the four arms to a named object ("upper right chakra, upper left conch, lower right gada, lower left lotus") gave a correct four-armed Vishnu on both tries. Nano Banana Pro stills cost 0 credits (balance stayed 90). Series order is the owner's call: Vishnu/Kurma episode first, Shiva after. |
| 2026-11-11 | Karthika (Instagram audio) | **Instagram's licensed songs only work inside the app.** Never bake them into the file or download them. Make two exports: narration only for Instagram (owner adds the song in the app, narration ~100 %, song 15–25 %), and a version with a YouTube Audio Library track mixed in for YouTube. Music mix: loudnorm the track to about -27 LUFS under a -16 LUFS voice, fade in 1.2 s and out 2.4 s, copy the video stream (no re-encode). |
| 2026-11-11 | Karthika (YouTube) | Upload and schedule works in Studio through Claude in Chrome: `file_upload` on the file input (under 10 MB), title and description typed in Telugu (a long type can time out for 30 s but still completes; wait, then screenshot), set not-for-kids, **AI use = Yes**, then Schedule. The time box is a dropdown in 15-minute steps (scroll the list; typing does nothing). Confirm the time zone shows GMT+0530. The scheduled video stays private until then. Only do this on the owner's explicit say-so. |
| 2026-11-11 | Karthika (backups) | A 190 MB project backup exceeds a 10-minute foreground limit. Run `scripts/backup.sh` through `systemd-run --user` and check the log; then verify with `rclone check`. |
| 2026-11-11 | Browser work | I navigated the owner's own open Flow tab to look at an Instagram page. Always open a new tab for anything new and close it after. Flow's screenshot size changes between sessions (1568×745 vs 1556×784): re-read coordinates from a fresh screenshot before clicking. |
| 2026-11-11 | Samudra Manthan (casting) | The "no women among the Devas" problem is solved by wording: "ONE single man only, no women" plus jaw, beard and chest words, and never "beautiful/graceful" for men. Indra and Bali came out male first try. Vasuki works with "ONE single cobra, ONE head, ONE continuous body, wound once around the mountain". Make single-character portraits first, big faces, then use them as references. |
