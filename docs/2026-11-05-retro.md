## Failures and fixes

### Video and editing

| What went wrong | Why | Fix / rule now |
|---|---|---|
| First AI reel (15 Oct) kept viewers **2 s** on average, 0 shares | Opened on a slow macro, black grid tile, caption about me, wrong music | Open on the face/hero as frame 1; set a cover; caption for the viewer; fitting audio (`templates/publish.md` hook check) |
| Telugu captions mis-shaped (వెలిగిస్తాం, క్షీరసాగర broken) | ffmpeg `subtitles` filter uses simple shaping | `captions.sh` converts to ASS and renders with `ass=…:shaping=complex` |
| Banner Telugu broke again | `drawtext` cannot shape Telugu; ASS **letter spacing** (Spacing ≠ 0) breaks clusters; Telugu font has no Latin glyphs | Use ASS + complex shaping, Spacing 0, switch to `Noto Sans` for Latin with `{\fnNoto Sans}` |
| `roughcut.sh` faded in from black | Default 0.4 s fade-in | No fade-in unless `--fade-in`; first frame = hook |
| `roughcut.sh` cropped off-centre to hide AI watermarks | Old script | Centred fill only; never hide the Flow/AI watermark |
| Clip 01: eyes closed 1.5–3.0 s | Veo made a long blink | Check eyes/face with labelled 0.5 s frame strips; used 4.0–7.3 s |
| Clip 07: woman walks out of frame after 3.5 s | Veo continued the action | Use only 0.5–3.5 s |
| **Clip 10: gold coins flying across her face + a flame streak** (owner spotted at 26–29 s) | Prompt mentioned coins + fireworks on a close-up; Veo scatters particles over the face | Replaced with a slow push-in (ffmpeg `zoompan`) on the clean still: 0 credits. Keep particles away from faces in prompts |
| Last caption ended 1.3 s before the video | `text.srt` timed to 28 s, cut was 29.3 s | Retime the last caption to the real cut length |
| Inline comment in `cut_list.txt` would have broken parsing | Comment on a data line | Comments only on their own lines |

### Browser automation (Chrome, Gemini, Flow, YouTube)

| What went wrong | Fix / rule now |
|---|---|
| Chrome asked "where to save" for every download | Owner turned off "Ask where to save each file" (`chrome://settings/downloads`) |
| Gemini "Download full size" click sometimes did nothing | Button appears before the image is ready: wait ~8 s, `scrollIntoView`, then click; retry once |
| Typed a prompt before the Gemini page finished loading → not sent | Wait for the page, then type; check the prompt appears in the chat |
| Flow grid shifts when a new placeholder appears → right-clicked a placeholder whose only option was **Delete** | Screenshot before every right-click; confirm the menu has Download/Animate before clicking; Escape otherwise |
| Flow "costing 10 credits?" question was scrolled out of view (looked stuck ~3 min) | Scroll the agent panel to the bottom before waiting longer |
| Browser `file_upload` limit is 10 MB; the Short was 15.5 MB | Two-pass re-encode to 2.3 Mbps → 8.8 MB, same 720×1280 |
| YouTube Studio "Leave site?" warning after Publish | Stale warning: confirmed "Changes published" toast first, then navigated with force |
| New channel picture/banner not visible on the public page right away | YouTube propagation delay (minutes to hours); Studio shows it saved |
