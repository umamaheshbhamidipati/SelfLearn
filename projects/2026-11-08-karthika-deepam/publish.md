- [ ] **First frame** is the strongest image (a face or the hero shot), not a slow detail or dark frame
- [ ] Something moves or changes in the first 1–2 seconds
- [ ] **Cover** set (Instagram grid tile and YouTube Shorts thumbnail), not a black frame
- [ ] Length 20–30 s, no dead seconds at the end
- [ ] Audio fits the mood (devotional / trending Telugu audio), added in the app's own library
