# Short-film script template

```
# <Title> (native script) — <Title> (English)
Format: ~N min, 9:16 | Language: <narration language> + short lip-synced lines | Genre | Look

## Characters
| Character | Look (copy into every prompt, identical) | Status (exists / make master still) |
All characters adults.

## Story in one line

## Acts
| Scene | Time | Beat |   (Legend → Problem → Threat → Darkest moment → Arrival/turn → Resolution)

## Script, per scene
| # | Shot | Source (REUSE / NEW / NEW + lip-sync) |
N:  narration line (native)  *(English)*
LS — Character: dialogue line (2–4 s max)

## Production numbers
shots total / reuse / new / lip-sync / credits (new × 10 × 1.5) / days

## Order of work
1 master stills → 2 test ONE lip-sync shot end to end → 3 generate scene by scene →
4 record narration + dialogue → 5 edit, grade, subtitle
```

Guidelines
- 30–40 shots for 4 minutes. Reuse earlier clips for legend/flashback scenes to save credits.
- Keep dialogue to 5–6 short lines; carry the rest with narration (no lip-sync needed).
- Have a native speaker check every non-English line before recording.
